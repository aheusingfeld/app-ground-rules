# User journeys

Each journey gets one file `JNN-<name>.md` with requirements and scenarios. Journey and step IDs (`J01`, `J01.S3`, `J01.U1`) are stable and shared by specs, contracts, tests and runtime events. Terms follow the [mental model](../mental-model.md).

This is the one list of all journeys, in the order users meet them. A journey without a stage is **explore**. When you add, rename, reorder or move a journey, update this table and the journey's milestone in the same change.
